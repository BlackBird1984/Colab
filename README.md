## 🔗 Verbindung zwischen Google Colab und GitHub

### 1. Aus Colab direkt in dieses Repository speichern:
1. Öffne dein Notebook in **Google Colab**.
2. Klicke im Menü auf:
   👉 **Datei** ➔ **Kopie in GitHub speichern...** *(File ➔ Save a copy in GitHub...)*
3. Falls noch nicht geschehen: Einmalig auf **„GitHub autorisieren“** klicken.
4. Wähle im Dialogfeld:
   * **Repository:** `BlackBird1984/Colab`
   * **Branch:** `main`
   * **Dateipfad:** z.B. `mein_notebook.ipynb`
   * **Commit-Mitteilung:** z.B. `Mabel Prompt Test`
5. Haken setzen bei:
   ☑️ **Einen Link zu Colaboratory einbinden** *(erzeugt automatisch den praktischen [Open in Colab] Button!)*
6. Klicke auf **OK** — fertig! Das Notebook ist sofort hier in GitHub gesichert.

### 2. Notebooks aus GitHub direkt in Colab öffnen:
* Gehe in Google Colab auf **Datei ➔ Notebook öffnen ➔ Reiter „GitHub“**.
* Gib `BlackBird1984` ein und wähle das Repository `Colab`.
* Klicke auf das gewünschte Notebook.
